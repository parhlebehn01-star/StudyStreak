# StudyStreak

I built this because I kept lying to myself about studying.
I needed something to hold me accountable.

Every habit app I tried had the same problem: miss one day, and it made me feel like a failure. So I made my own that does the opposite — it says something nice when I mess up.

## What it does

- You tell it "I studied today" or "I didn't"
- It keeps a streak
- If you miss, it shows you a quote based on your situation

That's it. No fancy features. No login. No ads.

## How to run

Make sure  Python 3 is installed
Open the project folder in a terminal
Run: python main.py

## Why it's not fancy

I only knew the basics of Python when I built this. So it's all in the terminal, it saves to a JSON file, and it's ugly. But it works.
## Tech used

- Python 3
- Built-in modules only: `json`, `os`, `random`, `datetime`
